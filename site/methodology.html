The gameplay information and estimated balance scores were recovered from the latest version of an interactive tool created in September 2026. These are not live game/server values. Revalidate against new patches.

Rankings

solo score = 14 × solo rating + 6 × threat rating. The source provided 1–5 solo and threat ratings, role labels and qualitative matchups. This is an Atlas-authored solo ranking, not an official rating or win-rate statistic.

Mutation fit scores

Each mutation has manually assigned 0–5 attributes (offense, defense, sustain, mobility, utility). A dinosaur role determines the attribute weighting. Circumstances add conditional value, while specific named mutation pairs receive synergy bonuses. The score is normalized to the best legal slot combinations found by a bounded search, then multiplied by the proportion of active slots filled. A 100 means “best fit in this model,” not invincibility or official optimality.

The comparison search considers the top 14 legal mutations per slot. This is a heuristic search and is not necessarily the global optimum across all combinations. Scores can change with context, sex, Prime status and number of slots.

Growth matchups

Important unresolved discrepancy: The Prime code peaks at 87% while the community guide says 87.5%; the non-Prime curve rises to 100% while that guide describes late decline. The source audit has not established current public-branch and server applicability, so the curves remain unchanged. See model and source comparison.

The growth combat-maturity curve and resulting 1v1 bins are estimates. The model uses dinosaur mass, threat and solo ratings, growth maturity, and favored/danger labels to create conservative indicative matchups. It does not simulate actual hitboxes, damage ticks, stamina consumption or pathing.

Prime and server profiles

The Atlas models normal with 3 slots and Prime with 4 from 75% growth. These assumptions remain community-informed and must be checked against the game client and the selected server. Official public EVRIMA is the default context; ORIGIN Main and ORIGIN Voice Chat are optional feature overlays. Selecting a profile changes published server context, not the underlying site-authored combat formulas or mutation eligibility.

Privacy & persistence

This static app has no backend, tracking, login, or server-side user database. Builds save only to this browser. Use the shareable build URL to carry selected settings across browsers/devices. Anyone with that link can see its build settings. Nothing is uploaded by the app.

Limitations

Some mutation availability, exact effects, server systems and dinosaur roster may have changed since this snapshot. Always verify after balance updates. This is a community strategy tool not associated with The Isle, its publisher, or ORIGIN.
