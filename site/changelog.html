Changelog

Application releases describe code changes, not new game-balance research. Gameplay-data snapshot: September 2026.

Version 1.0.2 — October 23, 2026

Maintenance-only release; no gameplay scoring or data changes.

  • Matchup browser checks now verify selected dinosaurs, generations, imported mutation chips and detached A/B lineage snapshots, including initial shared links and later hash changes.
  • Tests include deliberate incorrect-state checks to demonstrate that wrong imports, mutation displays, or modified planner state are rejected.
  • The footer version and accessible label are checked against the latest changelog heading using the package version, rather than matching old release text.
  • Expanded real Chromium checks at a 390px viewport for page overflow, actionable controls, footer navigation and readable changelog content; removed one unused helper.

Limitations: automated geometry checks at one narrow viewport are not comprehensive mobile-device testing; gameplay values remain heuristic, and saves synchronize through shareable links rather than a backend.

Version 1.0.1 — October 23, 2026

First documented application release; the previous package value 1.0.0 was not a tagged release.

  • Eliminated false fourth-slot warnings on valid non-Prime standard builds.
  • Custom builds can clear retained inactive fourth-slot selections without enabling Prime; those selections no longer block earlier-slot choices.
  • Unknown, duplicate, or ineligible restored mutations appear in their actual dropdowns as excluded and can be cleared or replaced.
  • Malformed or missing lineage generation values normalize consistently during planner restoration and matchup import, while invalid structures are rejected without partial state changes.
  • Added automated coverage and browser regression checks, plus this release history.

Known limitations: combat scoring remains a community strategy heuristic, not a win probability; growth unlock thresholds are approximate; local saved configurations do not automatically sync between devices (share links are supported).
