Changelog

Application releases describe code changes, not new game-balance research. Gameplay-data snapshot: September 2026.

Version 1.2.0 — October 25, 2026

Official-first context selection and clearer evidence applicability. The original combat-data snapshot stays September 2026; the latest substantive evidence review remains October 25, 2026.

  • Official EVRIMA public-branch profile is the default; optional ORIGIN Main and ORIGIN Voice Chat overlays expose only server-published 5× growth and custom features, not unverified combat changes.
  • Shared profile context persists between pages and in new build, Entomb and matchup share links; older links and saved builds remain loadable.
  • Source records now identify the officially announced 0.21.772 public patch; individual mutation effects, species mass/ranking and damage estimates are not elevated to official verified facts.
  • The prominent research label shows the latest evidence review rather than implying the September source-data snapshot was the latest verification.
  • Release consistency checks cover package, footer, accessible version, Sources page, README and latest changelog entry, with companion profile and browser regression cases.

Limitations: Server-specific mutation overrides, exact ORIGIN version/parity, and real combat telemetry remain unverified. No recalibration of role-fit, Prime or matchup coefficients.

Version 1.1.0 — October 25, 2026

Source-accuracy reconciliation and inspectable evidence; a bounded data/eligibility update, not a combat recalibration.

  • Official patch 0.21.720 removal of Traumatic Thrombosis now applies to catalog, legacy Custom Build, role presets, Entomb and Matchup Calculator. Historical saved identifiers remain visible as excluded.
  • Community-supported slots 2 and 4 added for Gastronomic Regeneration, Hypermetabolic Inanition and Tactile Endurance; unsupported blanket slot-4 unlockable assumptions removed. Default presets no longer include removed content.
  • Searchable Sources & Methodology page links mutation and calculator claims to named references and distinguishes official, server-published, community, disputed and site assumptions.
  • Documented exact weight/rating, growth, Prime, 1.12/0.86 matchup and legacy-view coefficients. Prime peak 87% vs community 87.5% and non-Prime elder decline remain unresolved and unchanged.
  • Expanded eligibility, historical-save, evidence-coverage and browser navigation checks.

Limitations: source review is not proof of exhaustive ORIGIN inventory or current mod behavior; exact unlock thresholds, omnivore rules and nesting inheritance require in-game/server confirmation. No Hordetest-only mutation is enabled. September 2026 original snapshot unchanged.

Version 1.0.3 — October 25, 2026

Matchup fight-condition verification and clarity update. No scoring recalibration or game-data refresh.

  • Verified in Chromium that a bleeding or low-health checkbox updates saved state, score, effects and marker only when the opposing dinosaur has an applicable active mutation.
  • Added explicit feedback for each selected condition explaining either the triggered mutation bonus or why the score remains unchanged.
  • Added model and browser regression checks for A/B directional bleed, low-health triggers, and unmutated no-effect cases.

Known limitations: Bleeding and low health are conditions for modeled mutations, not independent generic damage penalties. Combat scores remain heuristic; bleed damage over time, stamina and other unquantified mechanics are not simulated. Gameplay-data snapshot remains September 2026.

Version 1.0.2 — October 23, 2026

Maintenance-only release; no gameplay scoring or data changes.

  • Matchup browser checks now verify selected dinosaurs, generations, imported mutation chips and detached A/B lineage snapshots, including initial shared links and later hash changes.
  • Tests include deliberate incorrect-state checks to demonstrate that wrong imports, mutation displays, or modified planner state are rejected.
  • The footer version and accessible label are checked against the latest changelog heading using the package version, rather than matching old release text.
  • Expanded real Chromium checks at a 390px viewport for page overflow, actionable controls, footer navigation and readable changelog content; removed one unused helper.

Limitations: automated geometry checks at one narrow viewport are not comprehensive mobile-device testing; gameplay values remain heuristic, and saves synchronize through shareable links rather than a backend.

Version 1.0.1 — October 23, 2026

First documented application release; the previous package value 1.0.0 was not a tagged release.

  • Eliminated false fourth-slot warnings on valid non-Prime standard builds.
  • Custom builds can clear retained inactive fourth-slot selections without enabling Prime; those selections no longer block earlier-slot choices.
  • Unknown, duplicate, or ineligible restored mutations appear in their actual dropdowns as excluded and can be cleared or replaced.
  • Malformed or missing lineage generation values normalize consistently during planner restoration and matchup import, while invalid structures are rejected without partial state changes.
  • Added automated coverage and browser regression checks, plus this release history.

Known limitations: combat scoring remains a community strategy heuristic, not a win probability; growth unlock thresholds are approximate; local saved configurations do not automatically sync between devices (share links are supported).
