How scoring works

Scores compare each build to the strongest combinations found for that species’ role, slot count, sex, and selected circumstances. The Matchup Calculator uses a separate relative-pressure heuristic, including only explicitly modeled combat mutation effects; neither result is a win probability. Prime, terrain, player skill, pack size and game updates can change outcomes. Read the methodology.
